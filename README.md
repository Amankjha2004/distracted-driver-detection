
# Distracted Driver Detection Using Hybrid Deep Learning Techniques

## Project Overview
This project focuses on detecting distracted driving activities using hybrid deep learning techniques and multimodal datasets.

## Datasets
1. State Farm Distracted Driver Detection
2. 3MDAD Multimodal Driver Action Dataset
3. ThermalImagesDataset
4. UL-DD (planned; access pending)

Datasets are stored locally and are not uploaded to GitHub.

## Models

### State Farm and 3MDAD
- EfficientNetB3 + Vision Transformer
- ResNet50 + BiLSTM
- YOLOv12 + CNN Classifier
- DenseNet121 + SVM
- MobileNetV3 + Attention Mechanism

### Thermal Dataset
- CNN-BiLSTM
- CNN-GRU
- Transformer Encoder
